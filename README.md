# Mawasim Reports Demo

واجهة تجريبية احترافية لمنشئ تقارير عربي تابع لشركة خيالية باسم **حلول المواسم للأعمال**. تتيح للمستخدم إدخال بيانات منظمة، إضافة صورة، معاينة تقرير مؤسسي مباشرة، ثم تصديره أو مشاركته.

## المزايا

- نموذج عربي متكامل مع دعم RTL وتحقق واضح من البيانات
- بيانات تجريبية جاهزة ومعاينة تقرير A4 متزامنة
- إرفاق صور JPG وPNG ومعاينتها داخل التقرير
- تنزيل التقرير كصورة PNG عالية الدقة
- طباعة محسنة تتيح الحفظ كملف PDF مع الحفاظ على العربية
- نسخ رابط مشاركة تجريبي وتغذية راجعة مرئية
- تصميم responsive مناسب للجوال وسطح المكتب

## التقنيات

- Next.js (App Router) وReact وTypeScript
- Tailwind CSS
- React Hook Form وZod
- Lucide React
- html-to-image
- IBM Plex Sans Arabic (self-hosted)

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## التحقق والبناء

```bash
npm run typecheck
npm run lint
npm run build
npm start
```

## النشر على Vercel

ارفع المشروع إلى GitHub، ثم استورده في Vercel. سيكتشف Vercel إعدادات Next.js تلقائيًا. لا يحتاج المشروع إلى متغيرات بيئة أو خدمات خارجية.

> زر PDF يفتح نافذة الطباعة الأصلية في المتصفح؛ اختر **Save as PDF / حفظ كملف PDF** للحصول على أفضل عرض للنص العربي.
